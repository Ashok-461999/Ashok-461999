⚡ **9x faster in production**
Work-order processing was 18 seconds. Profiled the hot path, found redundant DynamoDB reads. Per-request in-memory caching. Down to 2 seconds. No new infra, no architecture overhaul.

🛒 **Zero oversold under concurrent load**
FlashSale reservation system. Atomic Redis Lua script checks and decrements stock in one round trip 🔒 no distributed locks. Confirmed reservations fire into Kafka so the API stays fast regardless of consumer pressure.

🤖 **LLM in prod, not in a playground**
When rule-based scheduling can't satisfy machine + material constraints, OpenAI kicks in as a fallback inside the Lambda. Few-shot JSON prompting, strict schema validation. Returns valid JSON or fails safe 🚫 nothing hallucinated reaches the database.

💰 **AI Expense Tracker**
Built end-to-end. Smart categorization, spending pattern recognition, auto-tagging, insights on where money leaks. Not a ChatGPT wrapper. A full product from UI to infra.

🏭 **Full ERP system from zero**
Production 🔧 Inventory 📦 Sales Orders 🧾 Subcontracting 🔗 Job Work Orders 📋 HRMS 👥

🌐 **Client-facing Angular modules**
